# Maintenance Planning And Partial Outcomes

HH-208 follows the November 3 runtime audit of janitor run `6f8f4d070e20`: 699.487 seconds elapsed, 226.514 seconds in step durations, and 472.973 seconds outside those clocks.  The saved history establishes missing timing coverage; it does not attribute that interval to a particular doctor, filesystem call or kernel stall.

The retirement step now times planning, the lane doctor, candidate revalidation, apply, and its pre/post checkpoints together with the injected monotonic clock.  Planning failures retain elapsed time.  Each checkpoint is counted once; the final history includes the post-checkpoint write latency, while that checkpoint itself describes the instant its write began.

Run records add optional `overhead_duration_ms`: monotonic elapsed time minus recorded step durations, clamped at zero for millisecond rounding.  A backwards or nonfinite clock raises rather than disappearing into that clamp.  Overhead covers sampling, lock entry/release, outside-step checkpoints and child drain; it is an aggregate, not attribution.  Watch start time now includes its initial observation, and that observation runs inside the existing housekeeper lock and child barrier.  Busy/lock skips do not sample or advance a completed cadence; scheduler success/partial cadence policy is unchanged.

Step records add `incomplete`, default false for older records, while retaining `ran`, `skipped` and `failed` wire statuses.  A truncated scan or exhausted cleaner budget preserves action/byte evidence but produces a partial run and an explicit incomplete-step summary even when zero candidates were discovered.  `remaining_count` counts discovered candidates only; an unscanned remainder is unknown.  Actual failures retain the existing failed-versus-partial rule; an incomplete read-only observation cannot rescue a failed cleanup.  Completed records clear their current step and target.

Host probes use the existing owned process-group runner and remaining shared deadline.  Unavailable or malformed observations are marked incomplete, with missing disk evidence excluded from pressure decisions.  A watch lock skip starts no probe.  Owned child shutdown still holds serialization until termination is proven; this change never force-unlocks or releases an unknown child.

Mac `MaintainRun` and `MaintainStepResult` have explicit Codable keys and ignore the additive fields.  Their existing run outcome already accepts partial.  A standalone fixture compiled exact actual-source declarations from `Sources/Storage/MaintainModels.swift` and `CompanionMaintainRunResult` from `Sources/Companion/CompanionSnapshot.swift`; both current additive JSON and old JSON decoded, with partial and old ok outcomes respectively.  No native source, phone route, scheduler, retention policy or deletion guard changed.  The exact merged producer is `scripts/hoghunter-clean`: its JSON at lines 2415–2431 emits `scan_truncated`, `budget_exhausted`, `budget_spent`, `remaining_count`, `applied_bytes` and `disk_free_delta_gb`.  An injected test executes its actual main/report formatter with discovery/apply/probes mocked, then feeds that output to Maintain: 9,000,000,000 logical item bytes and +0.25 GiB observed available-space delta stay distinct, and a truncated scan with zero discovered candidates remaining reports partial.

Validation uses injected planning/checkpoint delays, zero/nonzero-byte truncated scans, mixed failure/incomplete records, backward records, a backwards monotonic clock, exhausted probe deadlines and lock-skip fixtures.  Tests use synthetic homes and mock cleanup/doctor work; no live maintenance is run.

Individual kernel/filesystem calls remain cooperative limits: Python cannot interrupt a stuck syscall.  The existing housekeeper mutation guard and store lock use blocking flock, and atomic checkpoint writes can wait on storage.  The outer watchdog remains the final containment boundary, and uncertain owned-child shutdown intentionally retains the lock.  This change exposes overhead but does not claim those residual waits are fully bounded or attribute the historical gap without phase evidence.
